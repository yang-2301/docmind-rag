# Security Overview

## Encryption and isolation

All traffic is encrypted with TLS 1.3 and all data at rest is encrypted with AES-256. Each workspace is logically isolated; storage keys are per tenant. Production access by Northwind staff requires hardware-backed multi-factor authentication and is recorded in an immutable access log.

## Certifications

Northwind Cloud holds SOC 2 Type II, ISO 27001 and ISO 27701. The most recent SOC 2 report can be requested from the trust portal under NDA. Penetration tests are performed twice a year by an independent firm; the executive summary is shared with Enterprise customers on request.

## Vulnerability handling

Critical vulnerabilities are remediated within 72 hours of confirmation, high severity within 14 days, and medium severity within 90 days. Customers can report issues to security@northwindcloud.example and receive an acknowledgement within one business day.
